> 最后更新：2026-11-12

## 0. 与课题总目标的关系

课题 PDF《基于 NVIDIA Isaac Sim 的 JetBot 视觉-激光融合建图导航与强化学习研究》要求三层能力：

1. **baseline**：Isaac Sim 场景 + JetBot + 相机/雷达/IMU + ROS2 Bridge → SLAM + Nav2 目标点导航；
2. **主要扩展**：视觉目标识别 → “寻找某类物体并导航过去”的语义目标导航（本仓库的感知链路 + 语义地图）；
3. **进一步扩展**：PPO/SAC 局部避障，替代或增强 DWB，并与经典方法做对比。

最终验收（PDF 第六节）：至少 1 类场景跑通建图导航系统；给出经典 baseline 与强化学习策略的
对比实验（成功率、碰撞率、路径长度、到达时间、轨迹平滑度）；交付课程报告、演示视频、
系统架构图与关键实验图表。

**11.27 是中间检查点**：只要求视觉链路和 PPO 链路各自跑通并接入，不要求最终精度；
语义导航闭环、baseline 对比、系统集成与评测放在 11.27 之后继续推进。

## 1. 验收口径

| 模块 | 11.27 要达到的效果 | 通过标准 |
| --- | --- | --- |
| 视觉 | 机器人靠近障碍时，输出**障碍类别 + 机器人坐标系下的位置**，供下游构建语义地图 | 流程跑通：Replicator 生成数据 → YOLO 训练 → ROS2 推理；不要求高精度 |
| PPO | **取代 DWB** 作为局部避障，在简单障碍场景中完成避障 | 流程跑通：环境可随机化、能训练、能推理；不要求策略收敛到很高水平 |

两条线都优先保证「能演示、可复现」，指标和精度放在第二位。

### 物体表与语义地图角色（2026-11-12 确认）

| 类别 | 角色 | 先验地图 | 语义目标 |
| --- | --- | --- | --- |
| `shelf` 货架 | 固定仓储结构、通道边界 | 是 | 是 |
| `wall` 墙体 | 固定边界 / 不可通行 | 是 | 一般否 |
| `box` 纸箱 | A 类局部障碍、堆料 | 动态加入 | 是 |
| `pallet` 托盘 | 较大局部障碍 / 通道封堵 | 动态加入 | 是 |
| `barrier` 挡板 | B 类通道封闭 | 动态加入 | 否 |
| `cart` 推车 | 大体积 / 后续移动障碍 | 否 | 是 |
| `sign` 标牌 | 货架编号、区域识别 | 否 / 附着货架 | 是 |
| `person` 人 | 后续动态障碍 | 否 | 后续可作目标 |

> **语义地图只做平面（2026-11-12 确认）**：不做三维重建、不做 3D 框，地图是二维占据栅格。
> 感知输出里的 `position` 只取 `(x, y)` 参与建图，`z` 仅用于判断是否落在地面上（过滤悬空/误检）。
> 激光用单线雷达的平面扫描即可，不需要点云建图。

语义地图侧的最小用法：以 `(class_name, track_id)` 为键，对多帧 `position` 做滑动平均/占据栅格，
`track_id` 丢失 `max_age` 帧后归档。感知只提供事实，不决定地图怎么更新。

## 3. PPO 链路（待航硕确认底座）

推荐方案：**Isaac Lab**（自带 PPO 实现、并行环境、域随机化），JetBot 作为差速底盘接入；
PPO 输出 `/cmd_vel`，替换 Nav2 `controller_server` 的 DWB，或用独立节点直接接管速度指令。

备选方案：Isaac Sim 自建 Gym 接口 + stable-baselines3，控制更细但工作量大。

无论哪套，最小闭环都是：

```text
reset(随机场景/障碍) → obs(激光/视觉/位姿/目标) → PPO → action(线速度,角速度)
   → step(碰撞/到达/超时奖励) → 训练 → 推理节点发布 /cmd_vel
```

## 4. 需要与航硕确认的问题

### 视觉

1. **具体识别哪些障碍资产？** 是否有现成 USD 清单/路径？类别名怎么定（中文/英文、与语义地图字段一致）？
2. 数据在**哪套场景**里生成：空地随机撒障碍，还是直接加载课题的仓库/房间 USD？
3. 障碍物的尺寸、数量、密度、摆放范围，以及相机安装高度/俯仰角，有没有场景实测值？
4. 语义地图对类别和坐标的字段约定（是否直接用 `object_poses` 的 JSON）。

### PPO

5. 云电脑的 Isaac Sim 是 **4.5**，是否同时装了 **Isaac Lab**？GPU 型号/显存？
6. 随机化范围：障碍数量/位置/尺寸、是否有动态障碍及其速度、每回合是否换随机种子？
7. 观测/动作空间：JetBot 差速（线速度 + 角速度）？观测用激光 + 位姿 + 目标点，还是加视觉？
8. 与 DWB 的对比指标：成功率、碰撞率、到达时间、路径长度？DWB 的 baseline 参数用哪套？
9. 训练/推理的算力与时间预算（11.27 前能跑多久）。

> 在 5–9 确认前，`rl/` 暂不写死实现；视觉线不受影响，可以先推进。

## 6. 风险与兜底

- **资产/场景迟迟不到位**：用 `dataset_config.yaml` 里的 primitive 几何体模式先出数据集和演示，
  类别名保持可配置，资产到位后只换配置、不改代码。
- **Isaac Sim 4.5 API 差异**：先跑 `--check`；脚本对 Writer/Orchestrator API 做了兼容分支，
  首次报错把日志发我，按实际版本改。
- **PPO 底座未定**：11.18 前没有结论就默认按 Isaac Lab 推进，保证有可演示的训练闭环。
- **算力不足**：降低分辨率/并行环境数，先用小场景证明流程，再扩规模。
