# JetBot语义导航进度发布 · 2026-11-12

本分支是开发进度快照，不是连续任务全部通过或新参数冻结声明。仅纯仿真。

## 实现范围

USD对象真值观测→语义对象地图→中文严格查询→可达接近点→原生Nav2任务→安全停止/取消。
支持最近/最远可达纸箱、显式货架排号、货架旁对象、多候选歧义和缺失参照拒绝。
最远按每个对象最短安全可达接近路径排序；排号由场地目录指定，不是视觉识别。
机器人在线定位仍用原生IMU+FAST-LIVO2+AMCL；不读取机器人truth做导航。truth轨迹仅离线评分。
没有实现同学负责的视觉模型、PPO训练或随机场景生成。

这些终点指标是实际机器人chassis相对自由空间接近目标的离线误差，不是到物体中心距离，也不是整段AMCL全局定位精度。尚未达到真实3cm/1–2°要求。

## 参数边界

原冻结Nav2 override与定位/安全源码保持不变：规划圆半径0.40m，padding0.01m，膨胀1m；实体保守圆0.34m；目标容差0.05m/0.05rad；最高0.8m/s、0.6rad/s；安全门扫描中心净距0.40m、预测1.5s。
独立语义机动配置额外采用中心到对象盒表面1.21m的接近距离，并在道具表面2m内发布原生0.4m/s限速，2.5m外发送0清除限速。原生DWB也同比缩小角速采样至约0.3rad/s，解除后恢复0.6rad/s。
这是可选的语义运行策略，不能把减速成功写成全程0.8m/s验证；不降低避障保护。
